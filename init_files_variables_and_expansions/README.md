# Init files, variables and expansions

- 0-alias: Creates an alias named ls that runs rm -f *.

- 1-hello_you: Prints hello followed by the current Linux username.

- 2-path: Adds /action to the end of PATH.

- 3-paths: Counts the non-empty directory entries in PATH.

## 4. Global variables

The `4-global_variables` script displays all environment variables using the `printenv` command.

## 5. Local variables

The `5-local_variables` script displays all shell variables, environment variables, and functions using the `set` command.

## 6. Create a local variable

The `6-create_local_variable` script creates a local shell variable named `BEST` with the value `School`.

## 7. Create a global variable

The `7-create_global_variable` script creates an environment variable named `BEST` with the value `School` using the `export` command.

## 8. True knowledge

The `8-true_knowledge` script adds 128 to the value stored in the `TRUEKNOWLEDGE` environment variable and prints the result followed by a newline.

## 9. Divide and rule

The `9-divide_and_rule` script divides the value of the `POWER` environment variable by `DIVIDE` and prints the result followed by a newline.

## 10. Love exponent breath

The `10-love_exponent_breath` script calculates the value of the BREATH environment variable raised to the power of LOVE and prints the result followed by a newline.

## 11. Binary to decimal

The `11-binary_to_decimal` script converts the binary number stored in the `BINARY` environment variable to decimal (base 10) and prints the result followed by a newline.

## 12. Combination

The `12-combinations` script prints all lowercase two-letter combinations in alphabetical order, excluding `oo`.

## 13. Floats

The `13-print_float` script prints the number stored in the `NUM` environment variable with two decimal places using `printf`.

## 14. Decimal to hexadecimal

The `14-decimal_to_hexadecimal` script converts the decimal number stored in the `DECIMAL` environment variable to hexadecimal using `printf`.
