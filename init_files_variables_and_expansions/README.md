# Init files, variables and expansions

- 0-alias: Creates an alias named ls that runs rm -f *.

- 1-hello_you: Prints hello followed by the current Linux username.

- 2-path: Adds /action to the end of PATH.

- 3-paths: Counts the non-empty directory entries in PATH.

## 4. Global variables

The `4-global_variables` script displays all environment variables using the `printenv` command.

## 5. Local variables

The `5-local_variables` script displays all shell variables, environment variables, and functions using the `set` command.
